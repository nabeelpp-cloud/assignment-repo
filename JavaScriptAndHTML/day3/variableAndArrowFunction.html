Hoisting Behavior (var vs let vs const)

In JavaScript, variable declarations are hoisted (moved to the top of their scope) before execution, but the initializations are not hoisted.
var variables are hoisted and automatically initialized with undefined.
However, let and const variables are only hoisted by declaration and are not initialized, which causes a ReferenceError if accessed before their declaration.

Convert Normal Functions to Arrow Functions

Normal Function

                function multiply(a, b) {
                    return a * b;
                }
                function greet(name) {
                    return "Hello " + name;
                }

Arrow Function

                const multiply=(a,b)=>a*b;
                const greet=(name)=> "Hello "+name
